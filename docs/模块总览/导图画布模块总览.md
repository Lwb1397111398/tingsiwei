# 导图画布模块总览

## 模块职责

用 WebView 加载本地打包的 mind-elixir v5 页面（`file:///android_asset/mindmap/index.html`，离线可用）渲染/编辑思维导图，JS↔Kotlin 双向桥与 Room 里的 `mapJson` 同步（`MindMapPanel.kt:75-165`）。画布管交互与渲染，数据格式（mind-elixir JSON、`me-root`、`direction:2` SIDE）与「导图格式引擎」`TreeText.kt` 成对约定。

## 运作流程

**从哪来**：唯一调用方 `DetailScreen.MapTab`：`MindMapPanel(mapJson, editable = status==READY, onMapChanged = { vm.saveMap(it) }, onController = { controller = it }, darkTheme = isSystemInDarkTheme(), onPngReady = { vm.exportPng(it) })`；右上角浮层只剩「导出图片」一颗按钮（撤销/居中/缩放在画布底部工具条里，不再原生转发）。导图 WebView 常驻组合不销毁（切标签页盖不透明背景叠放 Box + 注释），缩放/平移状态切页不丢。

**怎么初始化**（`MindMapPanel.kt:96-136` factory）：`WebView` 开 JS/DOM storage（`:100-101`）、`allowFileAccess/allowContentAccess=false`（`:103-104`，asset 走 `file:///android_asset` 协议不受影响）；模拟器检测（FINGERPRINT/PRODUCT/MODEL，`:106-108`）命中则 `LAYER_TYPE_SOFTWARE` 强制软件绘制（`:109`，swiftshader 硬件合成丢内容的规避）；JS console 转发 Logcat `MindMapJS`（`:111-116`）；`onPageFinished` 置 `pageLoaded=true`（`:117-122`）；`addJavascriptInterface(MapBridge, "AndroidBridge")`（`:123-133`）；`loadUrl` 本地页（`:134`）。

**数据怎么进画布**（`update` 块 `:140-163`，三道闸）：

1. `pageLoaded` 未就绪直接 return（`:141`）——别在页面 JS 起来前 `evaluateJavascript`。
2. 推数据：`isInit`（`initedJson==null`）→ 发 `onController` 回调 + `ctl.init(mapJson, dark)`；否则仅当 `localJson != null && mapJson != localJson && mapJson != initedJson`（外部变化：AI 重写/恢复版本）才 `ctl.setData(mapJson)`（`:143-154`）。**防回环三件套**：自己拖动产生的 `mapJson` 变化会等于 `localJson`（回传时 `localJson = json` 双写：`:127` + `:146`），条件不满足就不回推——拖动→saveMap→Room 回流→画布不被重置。
3. `editable`/`dark` 变化才重发 `setEditable/setDark`（`:155-162`，diff 判存 `lastEditable/lastDark`）。

**JS 侧**（`assets/mindmap/index.html` 458 行）：

- 布局：`fixSize()` 用 `window.innerHeight/Width` 像素钉死 html/body/#map 三层（百分比链在部分 WebView 失效的规避），resize/load 都挂。
- 工具条：底部两行 14 个按钮（上行改结构：＋子 ＋同级 改名 删除 ↑ ↓；下行改视图：撤销 重做 － ＋ 适应 全开 收拢 居中），onclick 全接线；按钮禁用态随选中节点变化（根节点不可加同级/删/移动）。1:1 按钮已删（智能收起后首屏不再是全展开小字场景，回原字号用 ＋ 逐步放大即可）。
- **首屏智能视图** `applyAdaptiveView(data)`：先 `fitNow()`（scaleFit + 不低于 `MIN_FIT=0.55` + toCenter），若原始 fit 低于 `READABLE_SCALE=0.58` 且节点数 > 15，逐级收起深层分支（全展开 → `setViewDepth(2)` 二级可见 → `setViewDepth(1)` 一级可见），每级 refresh 后重新 fit；三级都达不到可读线时退回「二级可见」档——此时它与一级档同样被 MIN_FIT 钳在 0.55、观感相同但多显示一层内容。`appInit` 与 `appSetData`（AI 重写）都走这套。收起是**视图行为**，不回传存库（只有节点文字结构变化才触发 scheduleSave）。
- 展开/收起工具：`appExpandAll`（全部展开）/`appCollapseView`（收到二级可见），走 `getData()` 树改 `expanded` 再 `refresh`，同样只动视图不落库。
- 初始化 `appInit(jsonText, darkMode)`：先 destroy 旧实例；`opts.direction = ME.SIDE`（与 `TreeText.toMapData` 写入 JSON 的 `direction:2` 一致）、`draggable/editable/contextMenu` 开、**`overflowHidden` 必须保持默认 false**（只在 false 时才注册触摸手势，传 true 导图完全无法缩放）、`allowUndo: true`、缩放范围 0.15~3 步进 0.2；install `ME.nodeDraggable` 与 `ME.operationHistory`（v5.15.1 的 `nodeDraggable` 近乎空壳——真正的拖拽能力打包时已含，install 只是兼容动作）；`mind.init(data)` 后 80ms 走 `applyAdaptiveView`。
- 回传与联动：`mind.bus` 监听 `operation` 事件 → `scheduleSave()`（500ms 防抖）+ `updateButtons()`；监听 `expandNode` 事件 → `mind.scrollIntoView(node)`（节点跑出视野 50px 边距才平移回中央，大图上展开分支后新内容不再留在屏幕外）。
- **展开/收起圆钮（me-epd）的自绘**：mind-elixir 自带的 ＋/− 图标是 `data:text/plain` MIME 的 base64 SVG，本机 WebView 不渲染（元素在、背景图不画，2026-10-31 探针实测），且默认 18px 在画布缩放后只剩 ~10px——index.html 用纯 CSS 重画（白圆底 + `::before` 加减号 + `::after` 扩大热区，26px，配色吃主题 cssVar）；并在 **pointerup 捕获阶段自行切换**展开态、**click 捕获阶段 stopPropagation** 屏蔽库自带的 click 切换——库把切换绑在 click 上，触摸端该事件时有时无，双路并走会展开又收起净效果为零。
- 外部刷新 `appSetData`：`mind.refresh(data)` 后 50ms 走 `applyAdaptiveView`。
- `appAddChild` 无选中时兜底 `document.querySelector('#map me-root me-tpc')`（v5 自定义元素 `<me-tpc>` 不传节点不会默认用根）。

**桥的方法名规矩**（原生侧）：`MapController`（`MindMapPanel.kt:49-68`）所有指令都 `webView.post { evaluateJavascript(...) }`（`:51-53`）；JSON 字符串入参一律 `jsonArg()` 经 `JsonPrimitive` 转义（`:66`），杜绝手拼字符串注入；`MapBridge` 回调属性一律 Cb 后缀（`:21-25`，`:20` 注释：方法名和属性同名会递归调自己栈溢出——2026-09 实测踩过）。

**影响谁**：`onMapChanged` → `vm.saveMap` → Room（只在 READY 写库，双闸门见「详情页与生成编排模块总览.md」）；PNG 导出休眠（见坑 3）。

## 已知坑与约束

1. **`overflowHidden` 绝不能传 true**（index.html 注释）：这个构建里触摸手势（捏合缩放/单指平移）只在 `overflowHidden=false` 时注册，传了导图直接无法操作。
2. **CSS 只有一份且内联**：mind-elixir 样式经 `--minify --target=chrome80` 打进 `index.html`（源码含 CSS 嵌套语法，旧 WebView 不支持会整块丢弃 → 节点变透明隐形，README 坑节实测）；改样式要重新 esbuild 打包再生成，不能手改内联产物。
3. **mind-elixir 自带的 me-epd 图标在本机 WebView 不渲染**：图标是 `data:text/plain` MIME 的 base64 SVG，WebView 拒绝把它当图片画（元素存在、opacity/尺寸正常、背景图空白，2026-10-31 探针实测抓出）——index.html 已用纯 CSS 重画圆钮（白圆底 + 加减号）。若重新打包 MindElixirFull，此坑依然在，CSS 重画块必须保留。
4. **me-epd 的切换在触摸端不能依赖库的 click 处理**：库绑在 `map` 的 click 上，触摸端合成 click 时有时无；index.html 在 pointerup 捕获阶段自行切换、click 捕获阶段 stopPropagation 屏蔽库处理器——两条路都在时一次点击会展开又收起（净效果为零）。动这段代码前先想清楚双触发问题。
5. **收起/展开状态不落库是刻意设计**：`expanded` 只改视图，`scheduleSave` 只挂 `operation` 事件（节点结构变化）；用户收起后退出重进回到智能首屏。若将来要持久化收起状态，需显式补 scheduleSave 并评估对 `fromMapData`（不受影响）与 AI 改写链路的影响。
6. **`MapBridge` 回调属性必须 Cb 后缀**：`fun onReady() { onReady() }` 与属性同名会递归自己调，栈溢出——已踩过。
7. **初始化别依赖 JS→原生的 ready 信号**：JS 没起来就没人调 `appInit`（鸡生蛋死锁）；首推由 `pageLoaded` 驱动的 update 块完成。
8. **`MapController` 每次 update 现造**：它只是 `WebView` 的薄壳（eval = post+evaluateJavascript），无状态，重复 new 无害；但 `onController` 只在 init 那次回调，`DetailScreen` 持有的 controller 与 WebView 同生命周期，切页常驻所以够用。
9. **模拟器软件层判定靠三个 Build 字段**：`generic/sdk_gphone/Emulator`——自定义 AVD 命名不撞这三个词时会走硬件加速（真机行为），显示异常时先查这里。
10. **`AndroidView.onRelease` 里 `wv.destroy()`**：组合销毁即回收 WebView；若页面还持有未完成的 `scheduleSave` 定时器，回传会落空——500ms 防抖窗口内的编辑靠 `operation`→`saveMap` 尽力而为，落库前退出丢最后一次改动。
11. **在模拟器上用 adb 点画布做测试时，物理坐标 = WebView 屏幕偏移 + css 坐标 × 密度**：WebView 顶不在屏幕 0,0（上方有状态栏/标题/标签），`uiautomator dump` 拿 WebView bounds、`getBoundingClientRect` 拿元素 css 坐标再换算，别用截图像素直接猜。
