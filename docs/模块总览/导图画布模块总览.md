# 导图画布模块总览

## 模块职责

用 WebView 加载本地打包的 mind-elixir v5 页面（`file:///android_asset/mindmap/index.html`，离线可用）渲染/编辑思维导图，JS↔Kotlin 双向桥与 Room 里的 `mapJson` 同步（`MindMapPanel.kt:75-165`）。画布管交互与渲染，数据格式（mind-elixir JSON、`me-root`、`direction:2` SIDE）与「导图格式引擎」`TreeText.kt` 成对约定。

## 运作流程

**从哪来**：唯一调用方 `DetailScreen.MapTab`（`ui/DetailScreen.kt:261-297`）：`MindMapPanel(mapJson, editable = status==READY, onMapChanged = { vm.saveMap(it) }, onController = { controller = it }, darkTheme = isSystemInDarkTheme())`（`:280-287`）；右上角两按钮经 `MapController` 调「居中/撤销」（`:288-295`）。导图 WebView 常驻组合不销毁（切标签页盖不透明背景，`:196-212` 叠放 Box + 注释），缩放/平移状态切页不丢。

**怎么初始化**（`MindMapPanel.kt:96-136` factory）：`WebView` 开 JS/DOM storage（`:100-101`）、`allowFileAccess/allowContentAccess=false`（`:103-104`，asset 走 `file:///android_asset` 协议不受影响）；模拟器检测（FINGERPRINT/PRODUCT/MODEL，`:106-108`）命中则 `LAYER_TYPE_SOFTWARE` 强制软件绘制（`:109`，swiftshader 硬件合成丢内容的规避）；JS console 转发 Logcat `MindMapJS`（`:111-116`）；`onPageFinished` 置 `pageLoaded=true`（`:117-122`）；`addJavascriptInterface(MapBridge, "AndroidBridge")`（`:123-133`）；`loadUrl` 本地页（`:134`）。

**数据怎么进画布**（`update` 块 `:140-163`，三道闸）：

1. `pageLoaded` 未就绪直接 return（`:141`）——别在页面 JS 起来前 `evaluateJavascript`。
2. 推数据：`isInit`（`initedJson==null`）→ 发 `onController` 回调 + `ctl.init(mapJson, dark)`；否则仅当 `localJson != null && mapJson != localJson && mapJson != initedJson`（外部变化：AI 重写/恢复版本）才 `ctl.setData(mapJson)`（`:143-154`）。**防回环三件套**：自己拖动产生的 `mapJson` 变化会等于 `localJson`（回传时 `localJson = json` 双写：`:127` + `:146`），条件不满足就不回推——拖动→saveMap→Room 回流→画布不被重置。
3. `editable`/`dark` 变化才重发 `setEditable/setDark`（`:155-162`，diff 判存 `lastEditable/lastDark`）。

**JS 侧**（`assets/mindmap/index.html` 235 行）：

- 布局：`fixSize()` 用 `window.innerHeight/Width` 像素钉死 html/body/#map 三层（`:52-64`，百分比链在部分 WebView 失效的规避），resize/load 都挂（`:62-63`）。
- 工具条：底部 13 个按钮（`＋子 ＋同 改名 删除 ↑ ↓ 撤销 重做 居中 － ＋ 适应 1:1`，`:30-44`），onclick 全接线（`:210-222`）；按钮禁用态随选中节点变化（`updateButtons` `:75-84`：根节点不可加同级/删/移动）。
- 初始化 `appInit(jsonText, darkMode)`（`:103-143`）：先 destroy 旧实例；`opts.direction = ME.SIDE`（`:113`，与 `TreeText.toMapData` 写入 JSON 的 `direction:2` 一致）、`draggable/editable/contextMenu` 开、**`overflowHidden` 必须保持默认 false**（`:120-122` 注释：只在 false 时才注册触摸手势——捏合缩放/单指平移，传 true 导图完全无法缩放）、`allowUndo: true`（`:124`）、缩放范围 0.15~3 步进 0.2（`:125-127`）；install `ME.nodeDraggable`（`:131`）与 `ME.operationHistory`（`:132`，v5.15.1 的 `nodeDraggable` 近乎空壳——真正的拖拽能力打包时已含，install 只是保留的兼容动作，见 README 设计决策 #2）；`mind.init(data)` 返回 err 打日志（`:133-134`）。
- 回传：`mind.bus` 监听 `operation` 事件 → `scheduleSave()`（500ms 防抖，`:86-94`）+ `updateButtons()`（`:137`）。撤销/重做不显式调 `scheduleSave`（`:174-175` 只 `mind.undo()/redo()`），**是否落库取决于 operationHistory 的 undo 是否发 `operation` 事件——未实测**（README 已知缺陷 #5 的原话仍成立：真机若「撤销后退出重进又变回来」，就在 `appUndo/appRedo` 后补一次 `scheduleSave()`）。
- 外部刷新 `appSetData`（`:145-153`）：`mind.refresh(data)` 后 50ms 延迟 `scaleFit()+toCenter()`——AI 重写内容后让整图适应屏幕。
- `appAddChild` 无选中时兜底 `document.querySelector('#map me-root me-tpc')`（`:162-168`，v5 自定义元素 `<me-tpc>` 不传节点不会默认用根）。

**桥的方法名规矩**（原生侧）：`MapController`（`MindMapPanel.kt:49-68`）所有指令都 `webView.post { evaluateJavascript(...) }`（`:51-53`）；JSON 字符串入参一律 `jsonArg()` 经 `JsonPrimitive` 转义（`:66`），杜绝手拼字符串注入；`MapBridge` 回调属性一律 Cb 后缀（`:21-25`，`:20` 注释：方法名和属性同名会递归调自己栈溢出——2026-09 实测踩过）。

**影响谁**：`onMapChanged` → `vm.saveMap` → Room（只在 READY 写库，双闸门见「详情页与生成编排模块总览.md」）；PNG 导出休眠（见坑 3）。

## 已知坑与约束

1. **`overflowHidden` 绝不能传 true**（`index.html:120-122` 注释）：这个构建里触摸手势（捏合缩放/单指平移）只在 `overflowHidden=false` 时注册，传了导图直接无法操作。
2. **CSS 只有一份且内联**：mind-elixir 样式经 `--minify --target=chrome80` 打进 `index.html:6`（源码含 CSS 嵌套语法，旧 WebView 不支持会整块丢弃 → 节点变透明隐形，README 坑节实测）；改样式要重新 esbuild 打包再生成，不能手改内联产物。
3. **PNG 导出链路休眠**：原生侧 `MapController.exportPng`/`MapBridge.onPngCb` 全项目零调用，JS 侧已通（`index.html:194-208` → `onPngReady`）——接线只差 `Exporter` 一步（README 已知缺陷 #2）。
4. **撤销/重做是否落库未实测**：回传只挂 `operation` 事件（`:137`），`appUndo/appRedo`（`:174-175`）不显式 `scheduleSave`；若 operationHistory 的 undo 不发 `operation`，撤销结果不会进库（README 已知缺陷 #5，真机验证后补 `scheduleSave()` 或确认事件已覆盖）。
5. **`MapBridge` 回调属性必须 Cb 后缀**（`:20-25`）：`fun onReady() { onReady() }` 与属性同名会递归自己调，栈溢出——已踩过。
6. **初始化别依赖 JS→原生的 ready 信号**（`:117-122` + `:230` 只打日志）：JS 没起来就没人调 `appInit`（鸡生蛋死锁）；首推由 `pageLoaded` 驱动的 update 块完成。
7. **`MapController` 每次 update 现造**（`:142`）：它只是 `WebView` 的薄壳（`eval = post+evaluateJavascript`），无状态，重复 new 无害；但 `onController` 只在 init 那次回调（`:149`），`DetailScreen` 持有的 controller 与 WebView 同生命周期，切页常驻所以够用。
8. **模拟器软件层判定靠三个 Build 字段**（`:106-109`）：`generic/sdk_gphone/Emulator`——自定义 AVD 命名不撞这三个词时会走硬件加速（真机行为），显示异常时先查这里。
9. **`AndroidView.onRelease` 里 `wv.destroy()`**（`:137-139`）：组合销毁即回收 WebView；若页面还持有未完成的 `scheduleSave` 定时器，回传会落空——500ms 防抖窗口内的编辑靠 `operation`→`saveMap` 尽力而为，落库前退出丢最后一次改动。
